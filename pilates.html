Pilates

Eternah Fitness Center & Pilates for Women Only offers women-only Pilates classes designed to help improve core strength, flexibility, and optimal balance.

We also offer two types of Pilates classes: Reformer and Tower, designed to help improve posture.

Reformer Class

A Pilates class that uses a reformer to help strengthen core muscles, increase flexibility, and improve posture. Controlled movements are performed using a spring system, making the workout more effective and safe.

Tower Class

A Pilates class that uses a tower apparatus with various springs and bars to assist with stretching and strengthening exercises. This exercise helps improve flexibility, stability, and overall body control.

Cadilac Class

A Pilates class that uses the Cadillac apparatus to assist with stretching and strengthening exercises. This exercise helps improve flexibility, stability, and overall body control.
